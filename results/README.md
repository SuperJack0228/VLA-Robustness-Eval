# Raw Benchmark Results

This directory contains reproducible raw benchmark records and is excluded
from Git because the files are generated locally.

- `benchmarks/dynamic_displacement/`: paired V2/V3 raw CSV and JSON records
  for both final seed schedules.
- `benchmarks/chunk_size_ablation/`: paired raw records for chunk sizes
  1, 5, 10, and 20 across both final seed schedules.

Paper-ready figures, tables, and reports are kept in the repository-level
`final_report/` directory.
